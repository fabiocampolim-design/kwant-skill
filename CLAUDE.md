# Kwant — Theory and Practice: project instructions

Study-and-contribute project on **Kwant 1.5** (quantum transport, tight-binding).
Product: the notebooks in `chapters/` — `00_Contents.ipynb`, the twelve chapter notebooks
`01_…`–`12_…` (Parts I–II: core API, ten topological models, a reference shelf) and
`S1_Solutions_Part_I.ipynb` + `S2_Solutions_Part_II.ipynb` (every exercise solved and
asserted). The two monolithic notebooks were split into these on 2026-09-01 because a
7.4 MB notebook crashed editors: every notebook stays under 1 MB, opens with its own table
of contents, and figure numbering runs continuously across chapters (guarded by
`tests/test_notebooks.py`).
`AGENTS.md` is the complete machine-oriented description (files, commands, rules);
`docs/USER_MANUAL.md` the human one. Read them before touching anything.

## Environment

- Interpreter: whichever Python has Kwant. On the author's machine that is the
  conda **base** env (`%USERPROFILE%\miniconda3\python.exe`, Python 3.13); a fresh
  machine gets a dedicated env named `kwant` from `install_kwant_windows.ps1`.
- Jupyter kernel: **`kwant`** ("Python (kwant)") — every notebook is pinned to it; it is
  the name the installer registers. If it is missing:
  `python -m ipykernel install --user --name kwant --display-name "Python (kwant)"`.
- Packages: kwant 1.5.0, python-mumps, numpy (`<2.5` for `magnetic_gauge`; see README),
  scipy, matplotlib, sympy, qsymm, plotly, ipympl, nbconvert, pytest, pyflakes.
- Health check: `python verify_kwant.py` (ends "physically correct").
- Regression guard: `python test_thread_safety.py`.
- Full suite: `python -m pyflakes verify_kwant.py test_thread_safety.py tests dev docs`
  then `python -m pytest tests -q`; notebooks end to end with `KWANT_NB_EXECUTE=1`.

## Hard rules

- **MUMPS is not re-entrant.** Never call `kwant.smatrix` / `kwant.greens_function`
  from several threads at once — it segfaults the kernel. Use processes, a serial
  loop, or the SuperLU solver. `test_thread_safety.py` guards this.
- Run every changed chapter end-to-end (nbconvert --execute from `chapters/`, kernel
  `kwant`, one notebook at a time) — and all fifteen before a release — before claiming a
  cell count / figure count / "0 errors"; then update `tests/test_notebooks.py`,
  `README.md`, `AGENTS.md`, `CITATION.cff` and the manual together — the suite
  checks that the counts in prose equal the counts it asserts. A figure added to chapter
  *k* shifts the `_FIG_NO` start of every later chapter's Setup cell.
- pyflakes must be clean over the whole tree at every commit (CI runs it first).
- Licence texts are guarded (`tests/test_license.py`): keep `LICENSE`, `NOTICE`, the
  README's `### Disclaimer` and non-affiliation note, and the SPDX header of every
  script and every notebook.
- `tests/test_no_held_material.py` keeps the author's unpublished material out of
  every tracked file; the gitignored `private/` directory is where it lives. Never
  move anything from `private/` into a tracked file.
- Do not run anything in `dev/build-history/` (one-shot notebook rewrites, guarded).
- Upstream contact (issues, merge requests, the mailing list) is the owner's alone:
  `docs/drafts/` holds the texts and patches; never post or mail on anyone's behalf.
- Commit author is the owner's GitHub noreply identity (`git config user.email`
  is set per-repo); no personal e-mail, home-directory path or institution name
  anywhere in tracked files or notebook outputs (`tests/test_notebooks.py`).

## Layout

- `dev/` — standalone per-section development scripts the notebooks were built from
  (`dev18_ssh.py` … `dev27_ti3d.py`, `cells_a-c.py`, `sol_part1-2.py`, thread-safety
  repros; `build-history/` guarded one-shots, incl. `split_chapters.py`). See `dev/README.md`.
- `docs/` — user manual (md/html/pdf, built by `docs/build_manual.py`), numbered review
  docs (upstream audit, findings backlog, and other numbered reviews),
  `drafts/` (upstream issue texts + patches), `watch/` (weekly upstream watch reports).
- `scripts/` — `watch_upstream.py` (Kwant GitLab + clone delta) and
  `register_watch_task.ps1` (Windows Task Scheduler entry, Mondays 08:00).
- `course/` — the undergraduate course (linear deck, slides PDF/HTML fallbacks, handout,
  lecturer notes, figures), all generated by `course/build_course.py` from
  `course/deck/content_en.py` and the executed chapter notebooks; never edit `deck/index.html`,
  `deck/content.en.js`, `deck/slides.html`, `deck/slides.pdf` or `lecturer_notes.md` by hand.
- `tests/` — the pytest suite (see `AGENTS.md`, "Commands").
- Local study material, never tracked and never redistributed: `mirror/` (Kwant docs
  mirror), `papers/` (bibliography + reading notes), `upstream/` (clone of Kwant with
  the `contrib/thread-safe-mumps` branch and the watch state), `private/`.

Publication process, status and the owner's decisions are kept outside this
repository.
